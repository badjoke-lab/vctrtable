# vctrtable

A collection of independent Vector/WebXDC table games. The first game is Texas Hold'em with PvP as the primary goal.

Development is beginning. **No real-money wagering, cash redemption, or tradable chips.** The initial work is a WebXDC table lobby and independently tested poker rules. An actual PvP hand is not enabled until private dealing and authoritative ordering have been verified in Vector.

See `docs/ROADMAP.md` on the development branch for milestones.
